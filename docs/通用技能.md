# 🕵️ 监察师 · 通用技能（方法论）

> 一份**泛式 skill**：不依赖具体电脑，照着这个清单问问题、查环境、摸语言、查编码，就能系统掌握任何一台电脑的架构。
> 相关：`README.md` · `format/格式与编码.md` · `docs/知识图谱与RAG.md`

---

## 适用场景

换电脑、装新环境、排查编码问题、接手一台不熟悉的机器、写环境文档、设备盘点。

## 摸底顺序（5步，按此顺序最省事）

### 第1步：系统是什么
- 操作系统品牌 / 版本 / 构建号 / 架构位数 / 安装类型
- ⚠️ Win11 24H2+ 的 ProductName 可能显示 "Windows 10"，看构建号（26xxx=Win11）

### 第2步：硬件配置
- CPU（注册表 CentralProcessor） / 显卡 / 网卡 / 内存 / 磁盘
- ⚠️ 内存/型号常需管理员权限，查不到就标"待手动确认"

### 第3步：编程语言/运行时（核心）
对每种语言：装没装（`--version`）、装在哪（`Get-Command`）、包管理器版本、有无版本管理器。
```powershell
node --version; npm --version
python --version; pip --version; py -0
git --version
bun --version; uv --version; mise --version; rg --version
pnpm --version
```

### 第4步：编码与格式（最容易出错，必查）
系统UI语言 / 时区 / Windows代码页 / 控制台编码 / Python编码 / 文件换行

### 第5步：工具链/生态
编辑器（版本/语言/编码设置）/ 包管理目录 / 专用工具链目录（.cherrystudio、.dsh等）

## 标准提问清单（每个工具对照问）

- Node：版本? 路径? npm/npx版本? 全局包目录? 装版本管理器吗?
- Python：版本? 路径? pip版本? 几个版本(py -0)? 默认编码?
- Git：版本? 路径? 换行配置?
- 包管理器：pnpm版本? store在哪? bun/uv/mise/rg有没有?
- 编辑器：版本? 界面语言? 编码/换行设置?

## 排查决策树

```
代码/文件中文乱码?
├─ 是 → 编码与读取编码不一致 → VS Code右下角切换 或 命令检测
└─ 否
└─ 命令跑不起来?
     ├─ 工具没装 → 装运行时
     └─ 装了但PATH没有 → 用完整路径 或 加PATH
```

## 自检清单（每台电脑必答）

- [ ] 操作系统? 版本/构建号? 32/64位?
- [ ] CPU/显卡/网卡/内存/磁盘?
- [ ] Node/Python/Git版本和路径?
- [ ] 包管理器(npm/pip/pnpm/bun/uv)版本?
- [ ] 系统语言、时区、代码页?
- [ ] 控制台/Python默认编码是不是UTF-8?
- [ ] 文件换行LF还是CRLF? 编辑器怎么设置?
- [ ] 有没有专用工具链目录?
