## 三、关键规则（避免混淆）

1. **凡是你电脑的真实数据**（设备档案、财务数据、报表）→ 放**本地 Obsidian**，绝不传 GitHub。
2. **凡是通用的工具/方法/脚本**（扫描脚本、技能定义、插件、格式模板）→ 放**GitHub 模板仓库**，公开共享。
3. 运行时目录（日志/流程备份/上传文件/知识库）→ 本地 `_运行时\`，自动生成，自动归拢，不上传。
4. 这份清单本身 → 属于**规范/方法论**，放 GitHub 模板仓库的 `docs/` 里（公开），同时本地留一份。
