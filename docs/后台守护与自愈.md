# 🛡️ 监察师 · 后台守护与自愈框架

> **后台静默运行、周期检查、自动记录日志、出问题给安全修复指引。** 通用版，不绑定特定机器。
> 相关：`device-monitor-plugin/plugin.js` · `docs/通用技能.md` · `README.md`

---

## 是什么

监察师的后台常驻组件，它**不打扰用户**，但**一直在看着这台电脑**：

| 能力 | 做什么 |
|------|--------|
| 静默运行 | 装在 DeepSeek Harness，随会话存在，不占前台 |
| 周期检查 | 每小时心跳，确认系统正常 |
| 自动日志 | 每次检查写进 Obsidian 监察师日志文件夹 |
| 设备工具 | 提供 `check_device` 工具，随时扫描设备 |
| 技能发现 | 注册 `device-monitor` 技能 |
| 自愈指引 | 遇问题给出安全修复命令（不擅自乱改） |

## 运行位置

- 宿主：DeepSeek Harness（动态 Cordis 插件）
- 插件源码：`device-monitor-plugin/plugin.js`
- 日志目录：自动探测 Obsidian 笔记库 → `监察师\日志\`

## 自愈机制（只建议、不擅自乱改）

1. 先诊断：运行安全的只读检查命令。
2. 再给方案：给出安全修复命令，由你确认后执行。
3. 记录全程：诊断和方案写进日志。

**安全边界：**
- 不删除文件、不改注册表、不装软件（除非你明确同意）
- 需管理员权限/改系统的操作，只给命令不代执行
- 你没确认的修改，一律不做

## 提供的工具

### 🧰 `check_device`（设备检查工具）
扫描并返回本机设备信息（系统/CPU/内存/磁盘/GPU/网卡/编码/时区）。调用后返回 JSON。

### 🧰 `device-monitor`（监察技能）
可发现的技能，指向 Obsidian 监察师文件夹，让任何会话知道"监察师在这"。

## 如何停用/更新

- 临时停：`cordis_stop <pluginId>`（保留定义）
- 永久删：`cordis_undefine <pluginId>`
- 更新：定义新 Package 后 `cordis_run` 切换
