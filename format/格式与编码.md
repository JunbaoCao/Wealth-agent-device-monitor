# 🔤 监察师 · 格式与编码通用规范

> 这台电脑（任何电脑）文件/代码的格式规范：编码、换行、时区、语言区域。**通用版**，不绑定特定机器，扫描后填入实际值。
> 相关：`format/设备档案模板.md` · `docs/通用技能.md`

---

## 一、编码类型（先搞懂）

| 编码 | 是什么 | 什么时候用 |
|------|--------|-----------|
| UTF-8（无BOM） | 现代通用编码 | ✅ 源码/网页/配置文件首选 |
| UTF-8 BOM | 带文件头标记 | 部分Windows工具识别用 |
| ANSI/GBK (936) | 中文Windows传统编码 | ⚠️ 老记事本ANSI文件 |
| UTF-16/LE | Windows原生编码 | Windows系统内部 |

> **铁律：新代码一律 UTF-8 无 BOM，只有老文件才可能是 GBK。**

## 二、实测项（扫描后填）

| 项目 | 标准值 | 本机值（扫描后填） |
|------|--------|-------------------|
| Windows代码页 ACP | 936(GBK) 或 65001(UTF8) |  |
| 控制台编码 | UTF-8 最佳 |  |
| Python默认编码 | UTF-8 最佳 |  |
| Node.js编码 | UTF-8 |  |
| 文件换行 | LF 最佳（.bat/.cmd用CRLF） |  |
| 语言区域 | 视国家而定 |  |
| 时区 | 视地区而定 |  |

## 三、换行规范

- 代码文件：**LF + 末尾换行**（`.editorconfig` 设 `end_of_line = lf` + `insert_final_newline = true`）
- Windows批处理 `.bat/.cmd`：**CRLF**（cmd.exe需要）
- Excel/CSV文本：通常CRLF（视工具而定）

## 四、乱码排查（遇到乱码这样查）

| 现象 | 原因 | 解决 |
|------|------|------|
| 中文变`鏇瑰啗`乱码 | UTF-8文件被当GBK读 | 右下角编码→选UTF-8重开 |
| 中文变`锟斤拷` | GBK文件被当UTF-8读 | 右下角编码→选GBK/ANSI重开 |
| PowerShell中文乱码 | 控制台编码不是UTF-8 | `[Console]::OutputEncoding=[Text.UTF8Encoding]::new($true)` 或 `chcp 65001` |
| Python读中文乱码 | 没指定编码 | `open(f, encoding='utf-8')` 或 `encoding='gbk'`（老文件） |

## 五、自查命令

```powershell
Get-Culture                          # 语言区域
Get-TimeZone                         # 时区
[Console]::OutputEncoding.WebName    # 控制台编码
python -c "import sys;print(sys.getdefaultencoding())"   # Python编码
git config --get core.autocrlf       # Git换行
```
